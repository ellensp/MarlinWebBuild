    How it works

    1. Search for your printer and select its configuration.
    2. Choose a build environment (the default suits most boards).
    3. Click Request build. GitHub opens a pre-filled request. Submit it.
    4. A few minutes later a download link is posted on that request, and GitHub emails you.

    You need a free GitHub account to submit a request.
